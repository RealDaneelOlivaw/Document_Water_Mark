文档图片水印工具

Windows GUI 版使用说明（与仓库内 Go 程序行为一致）

程序能做什么

在 PPTX、DOCX 以及常见 图片文件 中，对嵌入或文件本身的位图绘制文字水印（图片级水印），并导出为新文件。

不支持 PDF。若只有旧版 .ppt / .doc，请先在 Office / WPS 中另存为 .pptx / .docx。

快速上手

  1. 双击运行 watermark-gui.exe（或自行从 go-app 构建生成的可执行文件）。
  2. 在左侧「文件选择」中点击 添加文件 选择多个文件，或 添加文件夹 递归导入整目录下所有支持的文件。
  3. 在右侧「参数设置」中填写或选择水印文字、字体、颜色、位置模式等（详见下表）。
  4. 点击底部 开始处理。进度条与状态栏会显示当前进度；「处理结果」文本框内逐条输出成功或失败原因。

输出文件命名

  • 新文件保存在与原文件相同的文件夹中。
  • 默认文件名为：原文件名_watermarked + 原扩展名（例如 报告.pptx → 报告_watermarked.pptx）。
  • 若该名称已存在，会自动使用 _watermarked_2、_watermarked_3 … 直到不冲突为止。
  • 勾选「删除原文件只保留带水印文件」时，处理成功后会尝试删除输入文件；若删除失败，日志中会出现警告，输出文件仍保留。

参数说明与默认值

参数 说明 默认
水印文字 显示在图片上的文字内容，可多行。 超卓航科广州研究院
字体名称 通过「选择」从列表挑选本机可用字体。 微软雅黑
字号 (pt) 正整数。 12
透明度 0–100，数值越大水印越不透明。 6
颜色 通过「选择」使用预设颜色（黑/白/红等）。 黑色 #000000
旋转角度 水印文字旋转，单位度。 0
位置模式 tile 平铺；top_left / center / bottom_right 为单点 placement。 tile
横向 / 纵向间距倍数 平铺时控制水印之间的间距比例。 0.2 / 1.5
边距 X / Y (pt) 与页面或图片边缘的留白。 2 / 2
小图过滤 (%) 过小的图片可按面积比例跳过，避免徽标等被误加水印。 3
排除页码 启用后，跳过 PPT/Word 中的指定页（页码从 1 起）。支持逗号、中文逗号、顿号、分号分隔；可用区间如 3-5。示例：1,4,7-9。 默认关闭

支持的文件扩展名

.pptx、.docx、.jpg、.jpeg、.png、.bmp、.gif、.tif、.tiff

从源码构建

安装 Go 后，在 go-app 目录执行 .\build.ps1，产物一般为 dist\watermark-gui.exe。详见仓库根目录 README.md。

文档与程序版本以仓库内代码为准；若界面文案与本文不一致，以实际程序为准。
